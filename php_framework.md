PHP

We chose PHP because we wanted to learn something new. PHP is suitable for web projects and has many frameworks.

Options
Laravel + Eloquent

Laravel is a PHP framework and Eloquent is its ORM.

Pros: MariaDB/MySQL support, easy to learn, good documentation, migrations.
Cons: We need to match the models with our existing SQL database.

Symfony + Doctrine

Symfony is a PHP framework for larger projects and Doctrine is its ORM.

Pros: MariaDB/MySQL support, strong data modelling, migrations.
Cons: More complicated and harder to learn for our project.

Spiral + Cycle ORM

Spiral is a PHP framework and Cycle is its ORM.

Pros: MariaDB/MySQL support and good performance.
Cons: Too complicated for our project and has a smaller community.

Choice

We chose Laravel + Eloquent because it is the simplest option for our project. It works with MariaDB/MySQL, supports migrations, and fits well with our existing SQL database.
